Contact benchmark · 3D replays

Load a preview to explore saved states. Drag to orbit, right-drag to pan, and scroll to zoom. One 3D case is active at a time; plots stay visible. All panes show convex scene colliders; IPC’s solver uses triangle surfaces.

Some test cases have two sets of simulation parameters per backend: General is each backend’s baseline preset, used across all cases. Tuned increases solver iterations for snap wedge only (PhysX and Steel), with the same scene and drive settings. Exact parameters are folded below each case.

Timing hardware: NVIDIA GeForce RTX 4070 Laptop GPU (8188 MiB VRAM), NVIDIA driver 580.178.04. Host: Linux-6.8.0-45-generic-x86_64-with-glibc2.39, 32 logical CPUs.

Timing setup: one environment on GPU (CUDA), at 240 Hz. Each timed frame includes all physics substeps and GPU completion synchronization. Rendering, recording, control updates, state readback, setup, warm-up and compilation are excluded.
